# ЛидСливс24

Шуточная CRM, в которой всё устроено так, чтобы клиент **не купил**. Интерфейс повторяет amoCRM, но самые яркие кнопки здесь — «Перенести на после праздников» и «Отправить в аут», а продажа считается инцидентом.

Состав проекта:
- демо-CRM с бессрочным доступом без регистрации: воронка, карточки сделок, задачи, списки, почта, чаты, аналитика, магазин шуточных приложений «СливМаркет», настройки;
- пародийный лендинг, собранный по канонам курса «Лендинг за 1 день»;
- десктопная и мобильная версии.

Пародийный проект для портфолио. С amoCRM не связан.
