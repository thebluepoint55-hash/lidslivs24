# ЛидСливс24

**Сайт:** https://thebluepoint55-hash.github.io/lidslivs24/

Шуточная CRM, в которой всё устроено так, чтобы клиент **не купил**. Интерфейс повторяет amoCRM, но самые яркие кнопки здесь — «Перенести на после праздников» и «Отправить в аут», а продажа считается инцидентом.

Пародийный проект для портфолио. С amoCRM не связан.

## Что внутри

- **Лендинг** по 12 блокам курса «Лендинг за 1 день»: «Хотите уменьшить продажи? Теряйте клиентов», в первом экране живая мини-воронка, где лиды сами уезжают в «Слит (успешно)».
- **Демо-CRM без регистрации**, вход одной кнопкой:
  - рабочий стол с плитками «Конверсия в отказ», «Опасные сделки», рейтинг сливщиков;
  - воронка с перетаскиванием сделок мышью, как в amo, карточка сделки с лентой событий, окна «Причина слива», «Инцидент: клиент купил» и счёт в три подтверждения;
  - задачи: канбан по срокам и календарь, задачи тоже перетаскиваются;
  - списки, почта, чаты с шаблонами отмазок;
  - аналитика: шесть отчётов как в amoCRM;
  - «СливМаркет» — 17 шуточных приложений, часть из них реально меняет демо («Холодильник лидов», «Автоперенос Pro», «Прайс ×3»…);
  - настройки, профиль с достижениями, ИИ-ассистент «Отмаз», онбординг-тур.
- Десктопная и мобильная версии.

Демо живёт в рамках вкладки: изменения сохраняются при перезагрузке, а при новом открытии всё возвращается к исходным данным. Сервера нет, данные посетителей никуда не уходят.

## Разработка

```bash
npm install
npm run dev
```

Сборка — `npm run build`. Каждый пуш в `main` публикуется на GitHub Pages (`.github/workflows/deploy.yml`).

Стек: React 18, Vite, TypeScript, zustand, recharts, lucide-react, PT Sans.
