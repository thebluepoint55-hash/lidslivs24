# ЛидСливс24 — концепция и дизайн

## Идея

CRM №1 для отдела, который не продаёт. Абсолютно серьёзный интерфейс (копия amoCRM), который честно решает обратную задачу: помочь менеджеру сделать так, чтобы клиент не купил.

Цель проекта: кейс в портфолио + вирусный контент для Reels. Регистрации и оплаты нет — бессрочный демо-доступ в один клик.

## Правила юмора

1. **Каменное лицо.** Интерфейс, плотность, шрифты, иконки — как у настоящей CRM. Смешно становится, когда вчитываешься.
2. **Перевёрнутая иерархия кнопок.** Всё, что уводит от продажи, — яркие главные кнопки («Перенести на после праздников», «Отправить в аут», «Сказать, что дорого»). Всё, что ведёт к продаже, спрятано: «Выставить счёт» — серая ссылка в меню «…» и три подтверждения.
3. **Узнавание, а не абсурд.** Каждая шутка — реальная практика продаж: «клиент думает», «согласую с руководством», КП в пятницу в 18:55.
4. **Продажа = инцидент.** Финальный зелёный этап — «Слит (успешно)». Если клиент купил — красная карточка, форма разбора «Как это произошло и как не допустить впредь», уведомление руководителю.
5. **Метрики наоборот.** Конверсия в отказ, средний цикл сделки ∞, рейтинг сливщиков, достижения.
6. **ИИ-ассистент «Отмаз»** помогает вежливо отложить, написать письмо без ответа, придумать отмазку.

## Референс: amoCRM (снято с живого аккаунта 09.10.2026)

Копируем структуру и компоненты почти один в один, меняем только акцентные цвета.

### Типографика
- Основной шрифт — **PT Sans** (Google Fonts, OFL), 15px, цвет текста `#363b44`.
- Заглавные подписи (названия этапов, шапки таблиц, кнопки, заголовок раздела) — **PT Sans Caption**, 12px, bold, UPPERCASE, межбуквенный 0.5–1px. Названия этапов — цвет `#6b6d72`.
- Мелкий текст карточек (контакт, дата, события ленты) — 13px. Подписи в сайдбаре — 11px.

### Каркас
- **Сайдбар** 65px, фон `#1b3446`; сверху блок «Аккаунт» (аватар) на `#162b3a`. Пункты: иконка 30px + подпись 11px снизу. Неактивные — `#9da8ae`, активный — белый, bold, иконка цветная. Порядок: Рабочий стол, Сделки, Задачи (с красным бейджем-счётчиком), Списки, Почта, Аналитика, amoМаркет, Настройки. Внизу — круглая кнопка **чатов** с бейджем непрочитанных; открывает выезжающую слева панель диалогов (поиск сверху, строки: аватар, жирное имя, дата, серый превью-текст).
- **Шапка раздела** 64px на белом: название UPPERCASE (`СДЕЛКИ`), переключатель вида (канбан / список), поиск «Поиск и фильтр» с иконкой лупы, справа счётчик «13 сделок: 0 ₽», кнопка «…», белая кнопка «НАСТРОИТЬ» (рамка `#e8eaeb`), синяя «+ НОВАЯ СДЕЛКА».
- Фон рабочей области `#f5f5f5`.

### Кнопки
- Главная: фон `#4c8bf7`, рамка `#4077d6`, высота 38px, скругление 4px, текст 12px bold UPPERCASE `#f5f5f5`.
- Вторичная: белая, рамка `#e8eaeb`, текст `#363b44`.

### Воронка
- Колонки 312px, отступ ~16px. Заголовок этапа: название UPPERCASE по центру, ниже «N сделок: X ₽» 13px, под ними **цветная линия 2px**.
- Стандартные цвета этапов amo: `#99ccff`, `#ffff99`, `#87f2c0`, `#ffcc66`, `#f3beff`, `#ffcccc`, `#ff8f92`, `#fffeb2`, `#f9deff`, `#fffd7f`.
- «Быстрое добавление» — блок 50px с пунктирной рамкой `#c5c5c5`, скругление 4px.
- Карточка: белая, рамка `#c5c5c5` 1px, скругление 4px, padding 5px. Сверху строка: контакт 13px слева, дата 13px `#92989b` справа. Ниже — название сделки ссылкой 15px `#0057a9`. Внизу индикатор задачи — точка 5px (жёлтая `#e4b248` = задача сегодня, красная = просрочена, серая = нет задач).

### Карточка сделки
- Три колонки: левая панель ~355px, лента по центру, справа панель **«Виджеты»** 265px на `#e4e4e4`.
- Шапка левой панели тёмная (как сайдбар, с текстурой): «<» назад, название сделки белым bold ~22px, «…», под ним `#12345678` и кнопка-тег `#ТЕГИРОВАТЬ` 11px UPPERCASE `#687a82`; этап строкой с выпадающим списком и «(204 дня)» в этапе, под ним прогресс-бар по этапам; вкладки «Основное · Статистика · Файлы · Документы» (активная белая bold).
- Ниже на белом: поля «подпись `#92989b` 15px → значение», блок контакта (аватар, имя bold, «…», Компания, Мобильный), «+ Добавить контакт», «+ Добавить компанию».
- Лента на `#f5f5f5`: плашка-месяц по центру, системные события строками 13px `#6b6d72` («18.03.2026 17:53 Roistat Для поля «Название» установлено значение…», «Создание: 2 события Развернуть»), примечания — белые блоки с рамкой и иконкой слева.
- Внизу ленты — поле ввода: «Чат для всех: введите текст…» с переключателем типа.

### Остальные разделы
- **Рабочий стол**: на всю ширину фоновая картинка (синий градиент), логотип, поиск, кнопка «СОБЫТИЯ»; по центру название аккаунта; переключатели периода-«пилюли» (Сегодня / Вчера / Неделя / Месяц / Период) и «Все / Мои», «Настроить»; плитки тёмные полупрозрачные (скругление ~8px), заголовок UPPERCASE белым, большие цифры (фиолетовые/зелёные), круговые диаграммы.
- **Задачи**: канбан по времени — «Просроченные задачи» (красная линия), «Задачи на сегодня» (зелёная), «Задачи на завтра»; переключатель список/канбан, «ДЕНЬ НЕДЕЛЯ МЕСЯЦ», «+ ДОБАВИТЬ ЗАДАЧУ». Карточка задачи: контакт и компания, сделка ссылкой, дата красным при просрочке, «Связаться: Напомнить о себе».
- **Списки / Почта / Сделки-списком**: белая таблица с шапкой UPPERCASE серым, строки 40px, чекбоксы слева; в списке сделок этап — цветная плашка с цветом этапа.
- **Аналитика**: левое подменю 190px на белом (Анализ продаж, Сводный отчёт, Отчёт по сотрудникам, Список событий, Звонки, Цели), сверху кнопка «Фильтр» и название отчёта UPPERCASE. Анализ продаж — карточки этапов в ряд (СЕЙЧАС / ПЕРЕШЛИ В ЭТАП / ПОТЕРЯННЫЕ) и ниже воронка конверсии горизонтальными полосами цвета этапа с процентами. Сводный отчёт — линейный график «по дням / неделям / месяцам» и кольцевая диаграмма этапов + «Сделки по менеджеру». Цели — горизонтальные полосы (зелёные/красные) по сотрудникам, «По бюджету / По количеству».
- **amoМаркет**: шапка с поиском и «+ WEB HOOKS»; горизонтальные вкладки категорий (Установленные, Выбор amoCRM, Чаты и мессенджеры, Телефония, Email и SMS рассылки, Интеграция с веб-сайтом, Управление задачами, Счета и эквайринги, …); карусель промо-баннеров; секции «Название категории · Смотреть все (445)»; плитки приложений в 3 колонки: логотип 64px, название bold, звёзды и число отзывов, контурная кнопка «Установить бесплатно», диагональная лента-бейдж в углу. Вкладка «Установленные» — строки: логотип, название, категория, салатовая плашка «Установлено 17.07.2025», «Разработчик: …», кнопка «Отключить». Окно приложения: слева логотип, название, описание, статус «Установлен» + «Отключить»; справа «Настройки» с инструкцией и полями.
- **Настройки**: левое подменю (Обновление ВЕСНА 2026, Общие настройки, Счёт и оплата, Пользователи, Чаты и мессенджеры, amoAI, дальше настройки установленных виджетов), справа белые формы «подпись → поле», кнопка «Сохранить» вверху справа.

### Мобильная версия
Веб-версия amoCRM не адаптивная, на телефоне у amo отдельное приложение. Мобильную версию делаем по мотивам их приложения: нижняя панель вкладок, воронка — один этап на экран со свайпом, окна — шторками снизу.

## Палитра ЛидСливс24 (вариант 1 — «почти amo»)

Нейтральные цвета и размеры берём у amo как есть, меняем только акценты.

| Токен | Значение | Роль |
|---|---|---|
| `--sidebar` | `#13304f` | фон левого меню (у amo `#1b3446`) |
| `--sidebar-top` | `#0f2742` | блок «Аккаунт» вверху меню |
| `--sidebar-text` | `#9fb3c8` | неактивные пункты меню |
| `--accent` | `#2f80ed` | главные «рабочие» кнопки (у amo `#4c8bf7`) |
| `--link` | `#0057a9` | ссылки, названия сделок (как у amo) |
| `--anti` | `#ff5b36` | **анти-продажа**: самые яркие кнопки на экране |
| `--success` | `#27ae60` | «Слит (успешно)», цели слива достигнуты |
| `--danger` | `#e2574c` | «Инцидент: клиент купил», просрочки |
| `--text` | `#363b44` | основной текст (как у amo) |
| `--muted` | `#92989b` | даты, подписи полей (как у amo) |
| `--stage-title` | `#6b6d72` | названия этапов, события ленты |
| `--line` | `#c5c5c5` | рамки карточек (как у amo) |
| `--line-soft` | `#e8eaeb` | рамки кнопок и таблиц |
| `--bg` | `#f5f5f5` | фон рабочей области (как у amo) |
| `--widgets-bg` | `#e4e4e4` | правая панель виджетов в карточке |

Цвета этапов — стандартный набор amo (см. выше). Финальный «Слит (успешно)» — `#87f2c0`, свёрнутая «Оплата» — `#d0d0d0`, «Инцидент: продажа» — `#ff8f92`.

Правило: на одном экране не больше одной коралловой кнопки-героя. Иначе она перестаёт быть главной и шутка теряется.
